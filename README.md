# SC2001 Projects

Lab projects for SC2001 Algorithm Design and Analysis.

| Folder | Project |
|---|---|
| [`project-1`](project-1/) | Hybrid Merge Sort: merge sort that switches to insertion sort below a threshold `S` |
| [`project-2`](project-2/) | Dijkstra's algorithm: adjacency matrix + array queue against adjacency lists + min-heap |

Each folder has its own README with the experimental setup, the results, and
the commands to rerun the experiments from inside that folder. Both projects
need Java 17 or later (tested with Java 23), and Python 3 with `matplotlib`
for the plots.
